# hybrid-cyber-homelab
Serveur domestique multi-services optimisé pour Raspberry Pi 4. Basé sur Raspberry Pi OS Lite (64-bit) et Docker (Portainer/Dockge), ce projet fait tourner simultanément Tailscale, UpSnap (WoL), AdGuard Home et Vaultwarden. Une stack ultra-légère et sécurisée qui consomme moins de 1 Go de RAM sans aucune interface graphique superflue.
